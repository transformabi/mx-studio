## Dicas gerais pro Flow

1. **Sempre defina aspect ratio** no controle do Flow ou como sufixo `--ar 3:4` / `--ar 4:3` / `--ar 16:9` / `--ar 1:1` / `--ar 4:5`
2. Se algum resultado sair com watermark visível ou texto embutido, adicione `--no text, watermark, logo, signature` (Midjourney) ou "clean, no text overlay" (DALL·E)
3. Pra manter consistência dentro de uma categoria (ex: as 3 profissionais da clínica), tente usar o mesmo seed ou reference nas 3
4. Prefira **film grain / editorial** a HDR / hyperrealistic — o site tem vibe editorial
5. Se Flow oferecer "style presets", teste com "Kinfolk", "Editorial magazine" ou "Minimalist lifestyle"
